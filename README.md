# Kuzushi Beacon

**PvP中、自分が付与した「崩し」の相手を、細い線と頭上マーカーで見つけやすくするDalamudプラグイン。**

作者: **Roxyz0501** / API 15 / バージョン 1.0.0.6。公開プレビューです。ゲーム内での見え方・実戦での付与者ID・実負荷は未確認です。

## 導入

Dalamudの `/xlsettings` → Experimental → Custom Plugin Repositories に、共通リポジトリを追加します。

```text
https://raw.githubusercontent.com/Roxyz0501/DalamudPluginRepo/main/repo.json
```

`/xlplugins` で **Kuzushi Beacon** を検索してインストールし、`/kuzushibeacon` またはプラグイン一覧の設定から開きます。

## 表示と設定

- 自分が侍で、PvPコンテンツ内にいる間だけ動作します。通常エリア・PvE・ウルヴズジェイル係船場・他ジョブでは停止します。
- デバフの付与者IDが自分と一致する「崩し」だけを表示します。自分の地天が切れていても、相手に自分の崩しが残っていれば対象です。
- 設定画面で走査・候補・状態一覧・検知対象・描画数・投影失敗数を確認できます。1.0.0.4ではエリア移動中などの自キャラクター未取得で監視が停止したままになる不具合を修正しました。実戦での検知復旧は未確認です。
- 自分から相手への細い線、相手の頭上の下向き三角マーカーを、それぞれ個別にオン・オフできます。
- 線とマーカーそれぞれの色・透明度、線の太さ、マーカーの大きさ・高さ、表示距離、デバフ確認間隔を変更できます。
- 標準は線1.5 px、確認100 ms、表示距離50 mです。設定画面内のプレビューはPvP外でも利用できます。
- マーカーは足元に設定した高さを加えた位置へ描画します。骨格には追従しないため、種族やカメラに応じて高さを調整してください。
- 画面外・投影できない相手のマーカーは表示しません。線は自分と相手の両端が画面に投影できる場合に表示します。地形による遮蔽判定はありません。
- 表示は自分の画面だけです。共有ターゲットマーカーは設定しません。ターゲット変更と斬鉄剣発動は、下記コマンドを明示実行したときだけ行います。

## 自分の頭上の最大人数

LBゲージが満タンで、自分の崩しが付いた射程・視線の通る対象がいるとき、自分の頭上に最大巻き込み人数を数字で表示します。中心となる対象も含めた人数です（例：3は対象本人＋他2人）。LB未満・対象なし・キャッシュ期限切れでは非表示です。スタンやアニメーションロック中でも、LB満タンなら位置に基づく人数を表示します。

設定の「LB満タン時、自分の頭上に最大巻き込み人数を表示」で個別に切り替えられます。初期値はオン。数字の色・透明度と頭上の高さはマーカー設定を共用します。線と敵のマーカーをオフにしても人数だけ表示できます。全体のハイライト無効化では人数も非表示です。表示処理からターゲット変更・斬鉄剣発動は行いません。

既存の状態走査を共用し、人数計算は設定間隔ごと（標準100ms）、最大200候補です。人数表示がオンの間は表示距離設定に関係なくプレイヤー範囲の崩しを読み取ります。描画時はLBゲージと計算結果の期限だけを再確認し、消費後は次の描画で非表示にします。命中人数は現在座標からの推定です。

## 最適対象へのターゲット変更と斬鉄剣

マクロに次の1行を登録します（チャット入力からも使用可能）。

```text
/kuzushizantetsuken
```

PvP内で生存中の侍が実行すると、その時点で自分の崩しが付いているプレイヤーを読み直します。クライアントが発動可能と判断する対象の中から、対象周囲5mにいる自分の崩し対象数が最大の相手へターゲットを変更し、斬鉄剣を1回だけ試行します。同数なら現在のターゲット、次に自分から近い対象、最後にID順です。

対象なし・LB未準備・行動不能・射程外・遮蔽などでは発動しません。発動直前に付与者・対象ID・生存・使用可否を再確認します。クライアントが最終的に拒否した場合はターゲット変更だけ残ることがあります。プラグインによる別対象への再試行や発動待ちはしません。クライアント標準の先行入力処理は通常モードに委ねます。250ms以内の連続呼び出しはまとめて無視します。マクロへの `/ac` の追記は不要です。

この明示コマンドはハイライトの有効・無効、表示距離、確認間隔から独立しています。未使用時の追加ポーリングはありません。巻き込み判定は現在の3D座標の中心間距離による推定で、当たり判定半径・移動予測・各対象への遮蔽・無敵・機工兵器搭乗などのダメージ条件は人数へ反映しません。最終的な命中人数・撃破人数を保証するものではありません。実ゲームでのコマンド発動は未検証です。

## 通信・負荷

ハイライトはDalamud公開APIから読み取り、ImGuiでローカル描画します。明示コマンドではDalamudのITargetManagerで対象を変更し、FFXIVClientStructsのActionManager.UseActionをホットバー押下と同じ通常モード（UseActionMode.None）で1回呼び出します。ゲーム側の通常の使用条件・通信処理を利用し、不正なパケットの送信、独自パケットの生成・改変・再送、通信フック、クールダウン等の書換えは行いません。プラグイン自身のHTTP通信・DBアクセス・テレメトリーもありません。支援リンクは明示クリック時だけブラウザーで開きます。

PvP中は自キャラクターやジョブ情報が一時的に取得できなくても復帰を待ち、取得できない間・他ジョブの間は敵や状態一覧を走査しません。通常エリアではFrameworkの監視とオーバーレイ描画の購読を解除します。PvP中のデバフ走査は標準10回/秒。ゲーム全オブジェクトではなくプレイヤー用範囲を走査し、距離・生存状態で絞ってから状態一覧を読みます。描画時は一致した対象の位置だけを読み直し、状態一覧は再走査しません。最大200候補・200キャッシュ件。解除は次の確認時、期限切れは時間判定、退出・無効化・所有者変更ではキャッシュを消去します。

保存は変更時だけ600 ms遅延してまとめ、画面終了時にも確定します。閲覧・タブ移動・監視での書き込みはありません。計測結果と未確認事項は [VALIDATION.md](VALIDATION.md) を参照してください。

## 言語

日本語・English・Deutsch・Français・한국어・简体中文・繁體中文に対応。設定 → 言語設定で切り替えます。初回のみゲーム言語 → Dalamud UI言語 → Englishの順で決定し保存します。公開SDKに独立したランチャー言語APIがないため、その追加参照は行いません。手動で保存した言語は次回起動やキャラクター変更で上書きしません。Auto選択肢はありません。

7言語対応はプラグインの画面文字列に対するものです。ゲームデータの翻訳・変更は行いません。描画フォントはDalamud提供のNoto Sans CJKを使用し、フォントファイルは配布しません。

## 開発・出典

新規に開発した独立プラグインです。Dalamudと.NET 10 SDKを用意し、次のコマンドで検証できます。

```powershell
dotnet run --project Tests/Tests.csproj -c Release
dotnet build KuzushiBeacon/KuzushiBeacon.csproj -c Release
```

- [FFXIVClientStructs](https://github.com/aers/FFXIVClientStructs) (aers and contributors / MIT): ホスト同梱のActionManagerバインディングで使用可否・射程・遮蔽を確認し、通常のアクション実行を呼び出します。ソースやDLLは配布しません。
- [Dalamud](https://github.com/goatcorp/Dalamud) (goatcorp / AGPL-3.0): 公開ホストAPIのみを使用。ソース・バイナリーを同梱しません。
- [Bait Beacon](https://github.com/Roxyz0501/BaitBeacon) (Roxyz0501 / Apache-2.0): 言語正規化・翻訳辞書の基盤・フォント設定の一部を利用して本プラグイン向けに変更。共通タブはRoxyz0501の正式テンプレートをそのまま使用。
- [公式侍ジョブガイド](https://jp.finalfantasyxiv.com/jobguide/samurai/) のPvP説明を参照。
- [XIVAPI Status 3202](https://v2.xivapi.com/api/sheet/Status/3202?fields=Name,Description) でKuzushiの識別子を確認。実行時の外部API照会はありません。
- アイコンは `tools/Generate-Icon.ps1` による独自の幾何学図形です。ゲーム・第三者の画像素材を使用しません。
