# PvP Supporter

PvP向けの対象選択・崩し/斬鉄剣・攻撃機会・生存・味方の支援と、戦績記録をまとめたDalamudプラグイン。作者 **Roxyz0501**、API 15、**1.1.0.8**。

旧名Kuzushi Beacon。内部ID、リポジトリ、保存設定、旧コマンドは更新互換性のため維持しています。公開プレビューです。自動テストと描画検証を行っていますが、実ゲーム内の操作・検知・実負荷は未検証です。

## インストール・更新

Dalamudのカスタムリポジトリに次を登録し、`/xlplugins` で **PvP Supporter** を更新してください。

```text
https://raw.githubusercontent.com/Roxyz0501/DalamudPluginRepo/main/repo.json
```

設定は `/pvpsupporter`（旧 `/kuzushibeacon` も使用可）。公開ビルド以外でインストール済みDLLを上書きしません。

## 対象選択コマンド

通常のゲームマクロに1行ずつ記述できます。

| コマンド | 動作 |
| --- | --- |
| `/pvplowhp` または `/pvplowhp auto` | ジョブ連動の射程内で最低HPの敵を選択 |
| `/pvplowhp 3`、`/pvplowhp 5`、`/pvplowhp 20` | 指定した射程で選択。1〜20mを指定可能。近接・タンクは最大3mに制限 |
| `/pvplowhp3`、`/pvplowhp5`、`/pvplowhp20` | 固定射程の別名 |
| `/pvpnearest [auto\|距離]` | 射程内で最寄りの生存・選択可能な敵 |
| `/pvpally [距離]` | 射程内で最低HPの味方。初期20m |
| `/pvptrack` | 現在選択している味方を追跡対象にする |
| `/pvptrack clear` | 追跡解除 |
| `/pvpassist` | 追跡する味方が狙う、観測できた敵へ切替 |
| `/pvpztarget` | LB満タン時、斬鉄剣の推奨対象へ切替のみ |
| `/kuzushizantetsuken` | LB満タン時、推奨対象へ切替→通常の斬鉄剣実行要求 |
| `/pvpmute [秒]` | 通知音の一時ミュート。省略60秒、0で解除 |

初期値は **近接・タンク3m／遠隔・ヒーラー20m**。設定で変更できます。旧設定の最低HP射程は近接側に引き継ぎます。最低HPは割合ではなく現在HP実数です。同値は距離、さらに同値なら対象IDで決定します。距離は自分と相手の当たり判定半径を考慮した3D距離です。

対象選択はPvPコンテンツ内、生存中、明示コマンド実行時のみ。最大200対象を確認し、対象なしなら現在対象を維持します。連打は250ms、エラー表示は3秒間隔に抑制します。画面外でも取得できた対象は選択可能なので、「画面内限定」を独立設定にしています。画面内は投影範囲の判定であり壁の遮蔽判定ではありません。一般の対象選択は特定の攻撃の命中・使用成功を保証しません。

防御/既知の無敵状態の除外は、一般の敵選択と斬鉄剣で別設定です。斬鉄剣の防御除外は初期オフ。無敵は対応済みIDのみによる判断です。観測できない効果や未知の状態を安全と断定しません。

## 設定の構成

設定は左側のメニューで切り替えます。侍専用の項目と既存の線・マーカー・頭上人数は「ジョブ設定 → 侍」にまとめています。新しい表示・警告は基本的に初期オフです。必要な機能のチェックを入れてください。各ジャンルの有効化と一括オン/オフ、全体の有効化、通知全体、通知SE全体の切替を備えています。検証モードは一括オンの対象外です。

| 左側メニュー | 主な機能（依頼番号） |
| --- | --- |
| 対象選択 | ジョブ別/固定射程、最寄り、画面内限定、防御/無敵除外（2/4/5/8/9） |
| 攻撃機会 | 距離/射程色、リング/範囲円、範囲人数/低HP人数、上位3候補、現在との比較、安定条件通知、HP変化、候補一覧/理由（16〜30） |
| ジョブ設定 → 侍 | 崩し残り時間/期限色/通知/付与者区別、地天、LB通知、推奨対象、最低人数条件、要求状態、命中条件の目安。既存線/マーカー/頭上人数もここ（31〜45） |
| 生存支援 | HP/MP/急減警告、快気回数目安、防御/浄化準備と残り時間、対応状態異常、観測被タゲ数、接近/集中警告、死亡メモ（46〜60） |
| 味方・位置取り | 敵味方人数、孤立/人数不利、味方距離/中心方向/追跡、低HP味方、支援射程、アシスト/対象一致/集中対象、退避方向の目安（61〜75） |
| 通知・表示 | コンテンツ別機能セット、戦闘中のみ詳細、優先順位、種類別SE/音量/ミュート、色と記号、画面端方向、重なり調整、遠距離縮小（77〜85） |
| 振り返り | 試合集計、LB保持時間/機会/最大人数、コマンド/失敗理由、死亡近隣数/低HP後生存、設定メモ、匿名JSON（86〜95） |
| 軽量化・検証 | 必要機能のみ走査、更新間隔/件数/範囲計算予算、期限、操作しない検証、共用処理・主要機能別の時間/回数。既存走査設定もここ（96〜100） |
| 戦績・キルログ | 統合したPvP LedgerのK/D/A、キルログ、履歴、CSV、任意Discord通知 |

共通の言語・支援タブの実装は変更していません。既存機能と戦績機能は7言語。新しい支援タブは日本語/英語で、他の言語選択時は英語を使います。

補助設定（条件安定、解除時非表示、理由表示等）は対応する表示/通知を有効にした場合に適用されます。通常の低HP判定値は攻撃候補・生存・味方で共通。近隣味方数は自分を含みません。コンテンツ別設定は新機能のチェック集合を上書きし、数値・色・言語・既存線設定は共通です。

## 斬鉄剣・崩し

自分の付与者IDが一致する崩しを使用します。地天終了後も残存する崩しは有効。他の侍の表示は付与者IDが有効と判断できる場合のみ区別します。

斬鉄剣は対象中心半径5mの3D位置で巻き込み人数を比較します。中心も人数に含みます。同人数なら現在対象、距離、ID順で決定。中心対象は通常の対象可否と射程/LoSを確認し、実行直前にも状態を再検証します。周辺の全対象への遮蔽・着弾・確殺を保証する数字ではありません。

**LB未満では斬鉄剣の範囲計算を行いません。** 頭上人数はLB満タンかつ対象ありのときだけ表示。人数色、サイズ、高さ、上下オフセット、線の太さ、マーカー色/大きさは独立設定です。頭上プレビューは設定画面を開いているときだけ利用できます。通常の範囲人数（16〜30）は斬鉄剣とは別機能で、明示的に有効にするとLBに関係なく計算します。

実行は `UseActionMode.None`（通常ホットバー経路）。マクロから呼んでもプラグイン内の実行方式は通常ホットバー相当であり、ゲーム標準 `/pvpaction` のMacroモードとは異なります。正規のアクション実行にはゲームからサーバーへの通常の要求が発生します。独自パケットの生成/送信、ゲームの制限・リソース・クールダウンの書換えは行いません。

斬鉄剣コマンドは、実行されるたびに候補を再選択し、通常ホットバー相当のUseActionを1回呼びます。独自の250ms受付間隔、拒否後1秒・結果不明時3秒の待ち時間、要求済みによる入力抑制、GetActionStatusによる準備状態の事前拒否はありません。先行入力・硬直・発動可否はゲーム側に任せます。PvP・侍・生存・LB満タン、自分の崩し、対象の射程/遮蔽、設定した除外・最低人数・検証モードは維持します。候補がなければ実行しません。自動再実行なし、独自パケットなし。エラー表示のみ3秒間隔で抑制します。マクロから呼んでも標準マクロのMacroモードではなく通常ホットバー経路です。

## 戦績と記録

[PvP Ledger](https://github.com/Roxyz0501/PvPLedger) の機能を内蔵しました。「戦績・キルログ」で有効化してください。別プラグインのPvP Ledgerも動かすと記録や表示が重複するため、統合側を使う場合は旧プラグインを無効化してください。旧Ledgerの履歴ファイル/設定は自動移動しません。

試合開始でK/D/Aをリセットし、観測したキル/死亡ログを表示。終了結果を取得できた場合は正式値で確定します。フロントラインの試合中アシストは戦意高揚からの**推定範囲**であり、正式値とは区別します。受信結果の読取処理は対応ゲームビルド `2026.10.06.0000.0000` のみ有効。未知のビルドでは受信レイアウトを読まず、観測ログのみ記録します。受信ハンドラの本来の処理を変更しません。

Ledger履歴は最大1000試合/365日/128MiB、詳細1件1MiB、表示25件/ページ。変更のない再表示はキャッシュを使用します。CSVには選んだ履歴/イベントを出力します。Discordは初期オフ、設定したWebhookへ正式結果のみ送信し、送信前に重複防止記録を保存します。結果不明時の自動再送なし。URLはWindows DPAPIで保護します。

支援機能の集計は別の `support-review` に最大100試合/4MiB、匿名エクスポートは最新20件まで保存します。プレイヤー名やIDを自動記録しません。自由記入の試合メモはそのまま出力されます。死亡メモは直前約5秒、最大10サンプル/死亡、1試合最大50件。生存時間は低HP警告を有効にしたときの低HPエピソードから死亡までです。支援集計の永続保存には86を有効にしてください。

## 負荷と表示の限界

通常エリア/PvE/係船場では対象走査・支援描画を停止します。新機能は有効な機能から必要な情報を決め、1回のスナップショットを共有。支援表示の初期更新は200ms、上限200対象/30ラベル、一般範囲計算の初期予算2msです。描画から範囲探索や攻撃実行をしません。予算途中で候補走査を終えた場合は部分集計と明示します。一般範囲・撤退方向は地形/安全性を保証しません。

期限・本人確認・操作前検証は表示最適化をオフにしても維持します。機能98をオフにしても表示の絶対上限は2秒です。SEはローカル生成音で、音量調整は音声サンプルに適用し、ゲームの音量設定は変更しません。記録や設定は変更時だけ保存し、設定保存は遅延統合します。

## 開発・検証

`dotnet run --project Tests -c Release`、`HostTests`、`LedgerTests`、`UiTests` を使用。LedgerTestsは実装のモデル/保存/HTTPモックを検証し、実際のWebhook送信はしません。UiTestsはバックグラウンドで実UIコードを描画します。詳細は [VALIDATION.md](VALIDATION.md)。

操作経路の参考: [ActionManager](https://github.com/aers/FFXIVClientStructs/blob/main/FFXIVClientStructs/FFXIV/Client/Game/ActionManager.cs)、投影の参考: [Dalamud GameGui](https://github.com/goatcorp/Dalamud/blob/master/Dalamud/Game/Gui/GameGui.cs)。統合元と受信レイアウトの著作権表記は `NOTICE`、`Ledger-LICENSE.txt`、`PvpStats-LICENSE.txt` に保持しています。

上部タブは「PvP Supporter」「設定」「言語設定」「支援」。PvP Supporter内だけに左側メニューを表示します。「コマンド一覧・コピー」から機能別にコピーできます（コピーのみで実行しません）。コマンドの有無を切り替える設定はなく、射程・除外条件・最低人数・ミュート既定時間などの挙動を設定します。プラグイン全体の無効化、PvP・生存条件、連打抑制、検証モードは維持します。

敵選択の射程上限は近接・タンク3m、遠隔・ヒーラー20m、味方選択は20m。固定距離コマンドもジョブ上限を超えません。既存の上限超過設定は読み込み時に補正します。周辺の集計距離・描画距離・巻き込み半径は別設定です。

機能にマウスを重ねると詳細説明を表示します。オンの機能だけ直下に関連設定を表示し、複数機能で使う値は共通設定として表示します。全設定のコード接続監査と修正内容は [設定監査](SETTING_AUDIT.md) を参照してください。

### 1.1.0.3の設定階層

「ジョブ設定」の共通欄にLB満タン通知、その下の「侍」に崩しの表示・斬鉄剣サポート・通知を配置しています。崩し表示は、自分の崩し→マーカー/線/残り秒数→各見た目→残り秒数専用の期限色という順です。表示条件のLB満タン限定は崩し表示に適用し、推奨対象・頭上人数は常にLB満タン時のみ計算します。

斬鉄剣サポートをオフにすると推奨表示・人数と斬鉄剣コマンドを止めます。防御・既知の無敵の除外は侍の全表示・人数・コマンド・崩し通知で共有します。人数表示には色・文字サイズ・高さ・画面上下位置、敵の推奨対象には別々のマーカー/線の設定があります。色の数値入力はなく、ピッカーと表示専用RGBです。

崩しの新規付与通知と人数増加通知を統合しました。旧設定でどちらかが有効なら、共通・少人数・大人数の各プロファイルで新しい付与通知に引き継ぎます。通知・SEの全体オンオフと音量は全ジョブ共通です。

## 設定と履歴の保存（1.1.0.6）

設定は即時反映し、60秒ごとに変更分があるときだけ保存します。ログアウト・正常終了時にも未保存変更をflushし、正常な旧設定を3世代保持します。主設定が破損した場合は正常バックアップを復元して通知します。強制終了時の未保存分は復元保証がありません。保存失敗が3回続くと自動試行を止め、設定画面から再試行できます。

対戦ログとレビューはUTC開始日のディレクトリに試合単位で保存し、保持範囲の全日付を参照できます。旧対戦ファイルは移動せず参照、旧レビュー一覧は原本を残して一度だけ移行します。対戦の1000件/128MiB/365日、レビューの100件/4MiBという保持上限は維持します。

上部の「履歴ファイル」で保存場所、ファイル数、論理バイト数を確認できます。設定・キャッシュは集計対象外です。詳しい検証結果と制約は PERSISTENCE_AUDIT_2026-10-22.md を参照してください。

## 1.1.0.8: 斬鉄剣の理由表示・自動浄化停止

斬鉄剣コマンドの失敗時は、チャットMESSAGEに確認できた理由を表示します。PvP外、機能オフ、死亡、侍以外、LB未満／取得不可、自分の崩しなし、除外設定、射程／遮蔽・対象条件、最低人数不足を区別します。ネイティブ実行要求が受け付けられなかった場合は、観測したバインド・沈黙・スタン・睡眠・氷結・変身等、詠唱／硬直、取得できたゲーム側の使用不可コードを表示します。状態の存在は確認情報であり、サーバーから取得した確定的な拒否理由とは限りません。詳細不明の場合は不明と表示します。

要求受付・先行入力は発動成功とは区別し、LB消費未確認のまま3秒経過した場合はその旨を表示して監視を終了します。発動失敗とは断定せず、自動再送もしません。エラーMESSAGEと同種の例外ログは3秒間隔で抑制します。各明示入力の通常LB実行経路は維持しています。

**自動浄化は停止しました。** 旧版の保存設定がオンでも無効化し、設定項目・浄化の実行・解除待ちからの自動LB継続を削除しました。浄化は手動で使用してください。

全体の見直しで、通常の範囲人数／低HP人数／候補比較に、防御・無敵の除外設定が巻き込み対象まで適用されない問題も修正しました。

敵数の頭上表示は「生存支援 → 周囲の危険・死亡前の記録 → 自分を狙う敵の観測数」で設定できます。HUD／頭上オンオフ・色・文字サイズ・高さに対応します。観測できた敵の対象情報のみを数えます。

敵LB満タンハイライトは、敵IDとゲージを結び付ける確実な取得元が未確認のため未実装です。実ゲームでの発動・表示・負荷は未検証です。
